# 第 5 关 · 你的第一个自动化

> 半天，让 AI **替你干活**——不用你盯着，它自己跑。
> 前面几关是"你指挥它"，这一关是"它自己干"。做完这一关，你就是 Builder 了。

---

## 先听一个故事

老周在单位负责汇总各部门的周报。每周五下午，他要把 6 个部门的周报收齐、整理、合并成一份总报告发给领导。

这一件事，每周吃掉他一个下午。

他让 AI 搭了一条"流水线"：每周五下午 5 点，自动把所有周报抓过来、总结成要点、生成一份漂亮的总报告，然后发到领导的邮箱。

他第一次完整跑通的时候说："我这一下午，还给我了。"

**自动化 = 把"你每周都要做的重复动作"，变成"机器自己跑"。**

## 你要造什么

一条**自动化流水线**——你设置好一次，它以后每次都自己完成。

目标：消灭你生活/工作里一个**每周都要做、特别重复**的任务。

## 动手（半天）

### 第 1 步：找那个"每周重复"的任务（30 分钟）

想一想：**什么事情你每周都在做，而且做的时候内心在叹气？**

- 📊 汇总周报/报表（收集 → 整理 → 汇报）
- 📅 整理日程（把邮件/群里的事放进日历）
- 💰 记账（每周对一次账）
- 📣 内容发布（每周把文章/图发到 3 个平台）
- 📧 邮件筛选（把重要邮件挑出来，其余归档）

**选一个"叹气频率最高"的。**

### 第 2 步：画出你的流水线（30 分钟）

自动化就像流水线，先画清楚三个环节：

```
【触发】什么时候开始？  →  每周五 17:00
【动作】每一步做什么？  →  收集 → 整理 → 总结 → 发送
【结果】送到哪里？      →  领导邮箱 / 我的手机
```

拿张纸写下来。**写不清楚，AI 也做不清楚**——这一关考验的不是技术，是你能不能把流程讲明白。

### 第 3 步：用免费工具搭流水线（1 小时）

有一个免费工具专门干这个，不用写代码：

👉 **https://n8n.io**（或国内可访问的同类工具）
- 免费版（Community）自己部署或用云免费额度
- 或者用 **Google Apps Script**（免费，Google 账号就有，适合处理 Gmail/表格/日历）

以"每周汇总"为例，在 n8n 里这样搭：

```
1. 添加一个 Schedule Trigger（定时触发）：每周五 17:00
2. 添加 Gmail 节点：读取指定标签下的邮件
3. 添加 AI 节点（接 Gemini API）：把邮件内容总结成要点
4. 添加 表格节点：把要点写入 Google Sheets
5. 添加 Email 节点：把汇总发给你 / 领导
```

> 不会搭？直接问 AI：把上面这 5 步描述发给 AI Studio，让它帮你翻译成 n8n 里每一步该点什么、参数填什么。

### 第 4 步：先手动跑通，再交给它自动（1 小时）

**永远不要第一次就让机器自动跑。** 分两步：

1. **手动触发一次**：点"执行"按钮，看每一步有没有报错，结果对不对
2. **修到没问题了，才打开"定时"开关**

如果某一步报错，把报错信息复制给 AI：

```
我搭的自动化在第 3 步报错：<把报错信息贴进来>。怎么修？
```

### 第 5 步：连续跑两周，再迭代（30 分钟 + 两周观察）

- 第一周：定时跑通了，检查结果
- 第二周：看有没有"机器做错但你没发现"的地方
- 有问题就回去改流水线，没问题就让它继续跑

> ⚠️ 自动化省下的时间，**别用来做更多重复的事**——去做只有你能做的事。

## 你的作品

一条会自己跑、每周替你干活的流水线。**它在睡觉的时候也在工作。**

## 分享你的作品

截图流水线的运行记录（或展示一次自动生成的结果），发到社区：

> "我搭了条自动化流水线，每周五替我自动搞定【周报汇总】⚡"

## 这一关你学会了什么

- **自动化 = 触发 + 动作 + 结果**，把流程画清楚，机器就能替你做
- 先手动跑通，再开定时——**永远不要让没测试过的机器自动跑**
- 真正的 Builder，是把重复交出去，把时间留给创造
