# 第 5 关 · 你的第一个自动化

> 用半天搭一条会按时间自动运行的流程。
> 先手动跑通，再打开定时，之后每次都检查运行结果。

---

## 先看一个常见场景

老周负责汇总各部门周报。每周五下午，他要收齐 6 份材料，整理格式，再合并成总报告发给领导。

这套步骤变化不大，却几乎占满每周五下午。

他把流程拆成几个固定动作：周五 17:00 读取指定邮件，汇总要点，写入统一模板，再把结果发送到指定邮箱。

第一次跑通后，他仍会检查总报告，但不用再手动复制每一份周报。

自动化适合规则固定、重复发生，而且结果容易检查的任务。

## 你要造什么

你要搭一条自动化流水线，让它按设定的时间和步骤运行。

先选一个每周重复的任务。不要追求全自动，能稳定省掉其中几步就够了。

## 动手（半天）

### 第 1 步：找那个"每周重复"的任务（30 分钟）

回想一下：每周有哪些工作都要按同样顺序做一遍？

- 📊 汇总周报/报表（收集 → 整理 → 汇报）
- 📅 整理日程（把邮件/群里的事放进日历）
- 💰 记账（每周对一次账）
- 📣 内容发布（每周把文章/图发到 3 个平台）
- 📧 邮件筛选（把重要邮件挑出来，其余归档）

从步骤最固定、出错后也容易发现的那一项开始。

### 第 2 步：画出你的流水线（30 分钟）

自动化就像流水线，先画清楚三个环节：

```
【触发】什么时候开始？  →  每周五 17:00
【动作】每一步做什么？  →  收集 → 整理 → 总结 → 发送
【结果】送到哪里？      →  领导邮箱 / 我的手机
```

拿张纸写下来。如果触发条件、动作顺序和结果去向还说不清，先别急着打开工具。

### 第 3 步：用免费工具搭流水线（1 小时）

本关以不要求写代码的 n8n 为例：

👉 **https://n8n.io**（或国内可访问的同类工具）
- 免费版（Community）自己部署或用云免费额度
- 或者用 **Google Apps Script**（免费，Google 账号就有，适合处理 Gmail/表格/日历）

以"每周汇总"为例，在 n8n 里这样搭：

```
1. 添加一个 Schedule Trigger（定时触发）：每周五 17:00
2. 添加 Gmail 节点：读取指定标签下的邮件
3. 添加 AI 节点（接 Gemini API）：把邮件内容总结成要点
4. 添加 表格节点：把要点写入 Google Sheets
5. 添加 Email 节点：把汇总发给你 / 领导
```

> 如果不知道节点怎么配置，可以把这 5 步和当前界面写给 AI Studio，请它逐项说明该选哪个节点、填写哪些参数。照做以后仍要自己检查权限和输出。

### 第 4 步：先手动跑通，再交给它自动（1 小时）

第一次先不要打开定时。按下面两步测试：

1. **手动触发一次**：点"执行"按钮，看每一步有没有报错，结果对不对
2. **确认每一步和最终结果都正确，再打开"定时"开关**

如果某一步报错，把报错信息复制给 AI：

```
我搭的自动化在第 3 步报错：<把报错信息贴进来>。怎么修？
```

### 第 5 步：连续跑两周，再迭代（30 分钟 + 两周观察）

- 第一周：定时跑通了，检查结果
- 第二周：看有没有"机器做错但你没发现"的地方
- 有问题就回去改流水线，没问题就让它继续跑

> ⚠️ 每周留几分钟抽查运行记录。自动化会重复正确步骤，也会重复配置错误。

## 你的作品

你的成果是一条按周运行的流水线，以及两次经过检查的运行记录。

## 分享你的作品

截图流水线的运行记录（或展示一次自动生成的结果），发到社区：

> "我搭了条自动化流水线，每周五替我自动搞定【周报汇总】⚡"

## 这一关你学会了什么

- 一条自动化流程由触发条件、执行动作和输出结果组成
- 定时运行前必须手动测试；上线后也要定期抽查日志和结果
- 适合先自动化规则稳定的步骤，把需要判断的部分留给人处理
