# 第 2 关 · 你的第一个小工具

> 用 30 分钟做一个小工具，专门处理你生活里反复遇到的一件事。
> 这一关会多一个关键步骤：把输入、处理方式和输出结果写清楚。

---

## 先看一个常见场景

阿泽读中文系研究生。每周的读书笔记最让他头疼，尤其是刚打开空白文档的时候。

他做了一个"读书笔记生成器"。输入书名、作者和阅读时记下的三个关键词，工具会生成一份初稿。阿泽再对照原书补充自己的判断，而不是从空白页开始写。

室友看他用过一次，问："这玩意儿能借我用吗？"

阿泽说："这是我做的。"

这个例子和普通聊天的区别很小，但很重要：同一套输入规则可以反复使用，也可以交给别人使用。

## 你要造什么

做一个解决你自己某个具体问题的小工具。使用过程保持简单：

- 打开页面
- 输入几个信息
- 点按钮
- 得到结果

比如：
- 📝 **读书笔记生成器**：输入书名+关键词 → 生成笔记初稿
- 🍽️ **晚餐决策器**：输入预算+人数 → 生成一周菜单
- 💰 **零钱记账器**：输入收支 → 自动算结余
- 🎁 **礼物推荐器**：输入对方特点 → 推荐礼物

先选你自己会用的。需求越熟悉，你越容易判断结果到底好不好。

## 动手（30 分钟）

### 第 1 步：想清楚你要造什么（3 分钟）

先问自己三个问题，写在纸上或备忘录里：

1. **我生活里有什么重复的小麻烦？**（比如：每周不知道吃什么）
2. **这个麻烦的输入是什么？**（比如：预算、人数、忌口）
3. **我希望输出什么？**（比如：一周菜单）

> 先写清楚谁会用、输入什么、要得到什么。代码还没开始，这三个答案已经决定了工具的大半结构。

### 第 2 步：告诉 AI 你的想法（5 分钟）

回到 Google AI Studio（https://aistudio.google.com），新建一个对话，输入：

```
帮我做一个【晚餐决策器】网页工具，只有一个 index.html 文件。
功能：
1. 页面顶部有标题"今天吃什么"
2. 用户输入：预算（元）、人数（人）、忌口（可选填）
3. 点击"帮我决定"按钮后，随机生成一周 7 天的晚餐建议
4. 每条建议包含：菜名、大概费用、简单做法描述
5. 风格：可爱一点，暖色，按钮大
6. 全部中文
7. 输出完整的 HTML 代码
```

把【晚餐决策器】换成你自己的工具，把功能描述改成你第 1 步想清楚的输入/输出。

> **关键技巧：** 结尾保留"**输出完整的 HTML 代码**"，让 AI 返回可以直接保存和测试的文件。

### 第 3 步：让 AI 做出来（10 分钟）

AI 会输出完整代码。复制它，然后用上一关的方法打开：

- 在线预览：https://htmlpreview.github.io/ 或 https://codepen.io/pen/
- 或者保存为 `index.html` 双击打开

**测试它：**
- 输入预算 500、人数 3、忌口"不吃辣" → 点按钮
- 看它生成的菜单对不对

**发现问题就说（回到 AI Studio）：**

```
菜单里有辣的，我说了忌口不吃辣，请把辣的全去掉，重新输出完整代码。
```

### 第 4 步：让它变得好用（5 分钟）

观察你自己用的时候哪里别扭，然后指挥它改：

```
按钮点完之后，结果区域滚动到最下面，方便直接看到结果。重新输出完整代码。
```

或者：

```
增加一个"换一批"按钮，不刷新页面就能重新生成。重新输出完整代码。
```

每次改完，重新复制新代码 → 刷新预览 → 测试。

### 第 5 步：分享出去（7 分钟）

工具在你电脑上跑通后，可以用下面两种方式交给别人试：

**省步骤的方式**：把 `index.html` 文件发给朋友，他们双击就能打开用。

**更方便分享的方式**：部署到网上，得到一个可以直接打开的链接。

部署（推荐）：
- **Vercel**（免费）：vercel.com → 用 GitHub 或邮箱注册 → New Project → 上传你的 index.html → Deploy → 得到一个网址
- 或者用 **Netlify Drop**（更简单）：https://app.netlify.com/drop → 直接把 `index.html` 拖进去 → 得到网址

> 部署如果卡住了，可以先发文件。当前目标是观察 3 个朋友怎么使用，不必把时间全花在发布环节。

## 你的作品

你的成果是一个能完成"输入 → 点按钮 → 出结果"流程的工具。

找个朋友试试，看他用的时候会不会卡住，然后告诉 AI 改进。

## 分享你的作品

截图你的工具页面 + 你朋友用它时的反应，发到社区：

> "我做了个【晚餐决策器】，再也不用纠结吃什么了！谁要链接？"

朋友实际使用时的停顿和误操作，会告诉你下一版应该先改哪里。

完成后，进入下一关：做出你的第一个 AI 机器人。

## 这一关你学会了什么

- 一个小工具至少要说清楚三件事：**输入 + 处理 + 输出**
- AI 可以生成代码，你要负责定义功能、检查结果和安排修改顺序
- 先观察真实用户怎么用，再决定要不要增加新功能
