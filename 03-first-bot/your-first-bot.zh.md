# 第 3 关 · 你的第一个 AI 机器人

> 1 小时，做一个能**自动回答别人问题**的机器人。
> 从这一关开始，你造的东西开始**替你干活**了。

---

## 先听一个故事

大鹏是汽车销售，每天最头疼的不是卖车，是回答重复的问题：

"这车多少钱？""贷款怎么办？""保养贵不贵？"——同一个问题，他一天要回答二十遍，半夜还有客户在微信上问。

他花了一个晚上，用 AI 做了一个"购车顾问机器人"：把客户常问的问题和答案都装进去，做成一个网页链接，发到朋友圈。

从那以后，大部分问题机器人先答，答不了的再转给他。他说："我请了个不会下班的助理。"

**你不需要懂"人工智能"，你只需要把你脑子里的答案，装进一个网页里。**

## 你要造什么

一个**聊天机器人网页**——别人打开链接，输入问题，它自动回答。

你的朋友、同事、客户，都可以用。它回答的都是你设定的内容。

## 动手（1 小时）

### 第 1 步：想清楚机器人要会回答什么（5 分钟）

问自己：**你最常被问到的问题是什么？**

拿张纸，写下 5-10 个"你被问过最多的问题"和对应的答案。比如大鹏写的是：

- 问：这车落地多少钱？答：12.98 万起，含购置税，贷款首付 3 成。
- 问：保养一次多少钱？答：小保养 480，大保养 1200，首保免费。
- 问：可以试驾吗？答：可以，提前一天约，周末名额紧张。

> 这些"问答对"就是机器人的大脑。你写得越全，它越聪明。

### 第 2 步：去 Google AI Studio 拿一个免费钥匙（5 分钟）

打开：

👉 **https://aistudio.google.com/app/apikey**

用你的 Google 账号登录，点 **"Create API key"（创建 API 密钥）**，复制那串字符（形如 `AIza...`）。

> 🔑 这串字符是"钥匙"——**别发给别人**。它只有你自己用，免费额度对个人使用完全够。
> 如果不小心泄露了，回到这个页面删掉重建一把就行。

### 第 3 步：让 AI 生成机器人网页（15 分钟）

回到 AI Studio 的对话界面（https://aistudio.google.com），新建对话，输入：

```
帮我做一个聊天机器人网页，只有一个 index.html 文件。
背景：我是一个【汽车销售】，想做一个自动回答客户常见问题的机器人。

1. 顶部标题："购车小助手"
2. 中间是一个聊天窗口，用户输入问题，机器人回答
3. 内置这些问答（把【】换成你自己的问题答案）：
   - 问：【这车落地多少钱】 答：【12.98 万起，含购置税，首付 3 成】
   - 问：【保养一次多少钱】 答：【小保养 480，大保养 1200，首保免费】
   - 问：【可以试驾吗】 答：【可以，提前一天预约，周末名额紧张】
   - 答不上来的问题，机器人礼貌地说"这个问题我记下了，稍后人工回复您"
4. 右上角有一个"设置"小按钮，点开可以填入 API Key（保存在浏览器本地，不会上传到任何服务器）
5. 机器人用 Gemini API（模型 gemini-2.5-flash）回答
6. 风格：简洁、可信、蓝色调
7. 全部中文，输出完整的 HTML 代码
```

AI 会生成一段比较长的代码，没关系——**你只需要复制粘贴**。

### 第 4 步：复制代码、填钥匙、测试（15 分钟）

1. 复制 AI 输出的完整代码
2. 打开 https://htmlpreview.github.io/ 粘贴预览（或保存成 `index.html` 双击打开）
3. 点右上角"设置"，粘贴你的 API Key
4. 输入你的问题测试："这车多少钱？" → 看它怎么答

**发现问题就回去指挥 AI：**

```
机器人回答得太正式了，语气改成【像朋友聊天一样】，重新输出完整代码。
```

### 第 5 步：部署上线（20 分钟）

和上一关一样，用免费部署把机器人变成人人可访问的链接：

- **Netlify Drop**（最简单）：https://app.netlify.com/drop → 把 `index.html` 拖进去 → 得到网址
- 或 **Vercel**：vercel.com → 注册 → New Project → 上传文件 → Deploy

部署好以后，用**手机**打开这个链接试试——你的机器人已经可以"随身携带"了。

## 你的作品

一个会说话的网页链接。发给朋友：

> "这是我做的机器人，你随便问它问题试试。"

看他们问出什么你没想到的问题——**那些问题就是你的机器人下一版要升级的地方。**

## 分享你的作品

截图你和机器人的对话，发到社区：

> "我做了个机器人，替我省了每天重复回答的时间 🤖"

## 这一关你学会了什么

- **机器人 = 你的知识 + AI 的嘴**：你把答案给它，它替你说话
- API Key 是"钥匙"：自己用，别外传
- 造完一定要给真实的人用——**他们问的问题，才是你改进的方向**
