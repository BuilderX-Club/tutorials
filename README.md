## 现在开始（不用准备任何东西）

你不需要会写代码、不需要懂技术、不需要花钱。

你只需要：**一个愿意动手的心** + 一个免费工具。

**全程只用 Google AI Studio（Gemini）**：

👉 **https://aistudio.google.com**

一个 Google 账号（免费注册）就能用，浏览器直接打开，不用下载任何软件。

> 🚀 进阶选手也可以试试 **Codex**（OpenAI）或 **Claude Code**（Anthropic）——它们更强大，但对新手不友好。先把 AI Studio 玩熟，后面自然知道什么时候换。

👉 从 [第 0 关 · 你的第一次造物](00-first-build/your-first-creation.zh.md) 开始，10 分钟后你就有了第一个作品。（English? → [Level 0](00-first-build/your-first-creation.en.md)）

## 做出作品，加入社区

- 每完成一关，把你的作品**分享到社区**（Discord / 微信群），认识同路人
- 完成热身三关后，欢迎参加我们的线下 **Builder Day** 创作日，和一群人一起把想法做大
- 优秀作品有机会登上 **Demo Night** 舞台，被更多人看见
